# Calculator98.js
A nostalgic JavaScript calculator with a classic Windows 98/XP/7 style GUI
<img width="971" height="811" alt="windows98" src="https://github.com/user-attachments/assets/a07015cc-7021-4301-b86b-a0d354119aae" />
This project used [7](https://github.com/khang-nd/7.css)/[98](https://github.com/jdan/98.css)/[xp](https://github.com/botoxparty/XP.css).css frameworks
## Usage
This part assumes you already have Node.js and npm installed.
Before start:
```bash
npm install
```
To debug:
```bash
npm run dev
```

To build:
```bash
npx vite build
```
## Testing
The unit tests for calculator.js use the vitest testing framework. To run it:
```bash
npm run test
```
